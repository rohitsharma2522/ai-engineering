# Codex Project Instructions

## Security
- Never read, open, print, or modify `.env` files.
- Never access API keys, passwords, tokens, or credentials.
- Use `.env.example` to understand required environment variables.
- Never hardcode secrets in source code.
- Never expose secrets in logs, terminal output, or responses.

## Development
- Use Python and uv for dependency management.
- Use `uv add` to install dependencies.
- Follow existing project structure and coding conventions.
- Write clean, modular, maintainable code.
- Do not modify unrelated files.
